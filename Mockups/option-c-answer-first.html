What changes in Option C

Unlike Option B, this one needs real backend work. Read the cost lines.

  1. An answer, not a list. The user's question is answered in prose and the assets become evidence. This is the Perplexity / Glean model and it is what people now expect “AI search” to look like. Cost: a chat deployment on hokieopenai. You currently have only text-embedding-3-large — embeddings, no completions.
  2. Every claim is cited. Numbered citations map to the source cards below. Hover one to highlight its card; click to jump. Without this the answer is unauditable and unusable in a governance context.
  3. It streams. Tokens appear as they are generated, so a 4-second answer feels like a 0.4-second one. Cost: an SSE endpoint. /api/search is request/response JSON today.
  4. Grounding is stated, not implied. The footer says exactly what the answer was written from — catalog descriptions, not the data itself. This distinction matters enormously and is easy to get wrong.
  5. Retrieval trace is inspectable. Open it under the answer. Azure AI Search agentic retrieval returns an activity log natively — surfacing it turns “why did it say that?” into a two-click answer, and is a strong demo moment.
  6. Follow-ups do the next query for you. Suggested refinements, generated alongside the answer. This is where multi-turn value appears without committing to a full chat UI.
  7. Cards expand in place. The full userDescription markdown opens under the card. Still no preview pane — that is Option B's contribution, and the two compose.
  8. Latency is honest. Sources render first, then the answer streams over them. The user is never staring at a spinner.
  9. Failure mode to design for. Ask xyzzy. When retrieval returns nothing the model must refuse rather than invent an asset. That refusal path needs testing more than the happy path does.
  10. Ongoing cost. Every search becomes an embedding call plus a completion. At 3 rated searches a day this is negligible; at 3,000 it is a line item. Worth a cache on query_norm, which you already compute.
